# ai_entowork

Преобразование отчёта СКУД «Маршруты движения» в плоскую таблицу событий прохода.
Отчёт разбирают две небольшие нейросети на numpy: одна определяет, что находится в каждой
ячейке отчёта, другая по ФИО определяет пол сотрудника. Разбор отчёта и определение пола
выполняются автономно — без интернета и внешних сервисов. Сеть нужна только для
необязательного экспорта готовых данных в SeaTable.

## Что делает программа

1. Находит в каталоге `csv_in` последний созданный csv-файл.
2. Читает его (кодировка windows-1251, разделитель `;`).
3. Разбирает отчёт на события и определяет пол каждого сотрудника.
4. Записывает результат в `csv_out/ГГГГММДД-ЧЧММСС.csv` (кодировка windows-1251, разделитель `,`).
5. Экспортирует те же данные в таблицу SeaTable, если задан токен.

Если в `csv_in` нет csv-файла или файл пуст, программа останавливается с сообщением и
ничего не создаёт и не отправляет.

Колонки итогового файла:

| Колонка | Содержимое |
|---|---|
| Табельный номер | код ключа (карты), которым совершён проход |
| ФИО | фамилия, имя, отчество сотрудника |
| Дата | дата события в виде `ГГГГ.ММ.ДД` |
| Время | время события |
| Доступ | результат, например «Доступ предоставлен» или «Проход» |
| Дверь | точка прохода, например «Турникет3» |
| Событие | «Вход» или «Выход» |
| Подразделение | подразделение сотрудника из шапки отчёта |
| Пол | «М» или «Ж» |

## Установка и запуск

Нужен Python 3.11.

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Положите отчёт в `csv_in` и запустите из корня проекта:

```bash
.venv/bin/python main.py
```

Пример вывода:

```
Сотрудников: 67, событий: 1284
Файл 20261008-164731.csv успешно создан!
Экспорт в SeaTable: добавлено строк - 1284, дополнено - 0, без изменений - 0
```

Если сеть не уверена в поле сотрудника (уверенность ниже 90 %), в консоли появится строка
«Проверьте пол: …» — такие ФИО стоит проверить вручную.

Новый файл в `csv_out` создаётся при каждом запуске, даже если отчёт тот же самый.

## Экспорт в SeaTable

После создания файла данные отправляются в таблицу SeaTable (`export_to_seatable.py`).
Настройки подключения берутся из переменных окружения или из файла `.env` в корне проекта;
образец — `.env.example`:

```
SEATABLE_API_TOKEN=токен базы
SEATABLE_SERVER_URL=https://table.yanao.ru
SEATABLE_TABLE_NAME=Доступ в здание
```

Переменные окружения имеют приоритет над файлом `.env`. Файл `.env` содержит токен,
поэтому он внесён в `.gitignore`.

В таблице должны быть текстовые колонки с теми же названиями, что и в итоговом файле.

Экспорт не влияет на создание csv-файла: если токен не задан, экспорт пропускается, а если
сервер недоступен или таблица не найдена, выводится «Ошибка экспорта в SeaTable!» с
причиной. Файл в `csv_out` к этому моменту уже создан.

Повторный запуск не создаёт дублей. Событие сравнивается со строками таблицы за те же даты
по колонкам «Табельный номер», «Дата», «Время», «Доступ», «Дверь», «Событие»:

- если такой строки нет, она добавляется;
- если строка есть, у неё заполняются только пустые «Подразделение» и «Пол»;
- остальные данные в таблице не изменяются и не удаляются.

Если одно и то же событие дважды записано в самом отчёте СКУД, оно дважды попадёт и в файл,
и в таблицу; при повторных запусках таких строк больше не становится.

## Как устроены нейросети

Обе сети — полносвязные, с одним скрытым слоем (ReLU) и выходом softmax, написаны на numpy
(`ai/ai_network.py`). Обученные веса лежат в `ai/models/`.

**Сеть разбора отчёта** (525 входов → 48 нейронов → 9 выходов) получает признаки каждой
непустой ячейки и относит её к одной из ролей: ФИО, подразделение, дата и время, доступ,
дверь, код ключа, комментарий с входом, комментарий с выходом, прочее. Признаки ячейки —
её слова, слова соседней ячейки слева, ячейки над ней и всей строки, а также числовые
характеристики текста и положения. Благодаря этому сеть не зависит от шапок страниц и от
числа колонок: в отчёте встречаются страницы шириной 19 и 14 колонок.

**Сеть определения пола** (1024 входа → 32 нейрона → 2 выхода) получает окончания
фамилии, имени и отчества длиной от одной до четырёх букв и имя целиком.

## Обучение

```bash
.venv/bin/python -m ai.ai_train
```

Обучение занимает несколько секунд и перезаписывает веса в `ai/models/`. Если файлов с
весами нет, сети обучатся сами при первом запуске `main.py`.

- Сеть разбора отчёта учится на всех файлах из `csv_in` и на искусственных отчётах. Ответы
  для неё размечает набор правил в `ai/ai_train.py`; при обычной работе программы эти
  правила не используются.
- Сеть определения пола учится на 16 000 ФИО, которые случайно собираются из словаря
  `ai/ai_names.py`. Чтобы научить сеть новым именам или фамилиям, добавьте их в словарь и
  запустите обучение заново.

Если формат отчёта изменится, положите новый отчёт в `csv_in`, при необходимости поправьте
правила разметки и переобучите сети.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | точка входа |
| `csv_search.py` | поиск последнего файла в `csv_in`; если файлов нет, возвращает `None` |
| `csv_read.py` | чтение исходного отчёта |
| `ai/ai_main.py` | разбор отчёта, определение пола, сборка итоговой таблицы |
| `ai/ai_models.py` | загрузка и применение обученных сетей |
| `ai/ai_network.py` | нейронная сеть и её обучение |
| `ai/ai_features.py` | преобразование ячеек и ФИО в признаки |
| `ai/ai_names.py` | словарь имён, отчеств и фамилий для обучения |
| `ai/ai_train.py` | обучение обеих сетей |
| `ai/ai_writer_csv.py` | запись итогового файла |
| `ai/models/` | веса обученных сетей |
| `export_to_seatable.py` | экспорт готовых данных в таблицу SeaTable |
| `.env` | токен, адрес и имя таблицы SeaTable (в репозиторий не попадает) |
| `.env.example` | образец файла `.env` без токена |

## Ограничения

- Пол определяется по написанию ФИО. Если отчества нет, а имя редкое или не из словаря,
  сеть может ошибиться; в таких случаях она обычно сообщает о низкой уверенности.
- Сеть разбора отчёта проверена на одном настоящем отчёте и на искусственных. На отчётах
  другого вида её нужно переобучить.
- Экспорт в SeaTable проверен на тестовой таблице (первая выгрузка и повторный запуск без
  дублей) и на рабочей таблице: у 20 существующих строк одного сотрудника дозаполнены пустые
  «Подразделение» и «Пол».
